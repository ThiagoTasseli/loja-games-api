# 🕹️ E-commerce de Games - Projeto de Estudo

Este repositório reúne a construção de um **e-commerce de loja de games**, criado com o objetivo de aplicar na prática os conhecimentos adquiridos em **React**, **TypeScript**, **TailwindCSS** e **integração com APIs REST**.

---

## 🎯 Objetivo do Projeto

- Simular uma loja virtual de games com layout responsivo e moderno
- Criar componentes reutilizáveis e tipados com TypeScript
- Consumir dados de uma API externa (produtos, categorias, etc.)
- Trabalhar conceitos de estado global/local, hooks e rotas
- Aplicar boas práticas de organização de pastas e código limpo

---

## 🧩 Funcionalidades em Desenvolvimento

- Listagem de produtos da API  
- Página de detalhes do jogo  
- Carrinho de compras com controle de quantidade  
- Filtro por categoria/plataforma  
- Layout responsivo com TailwindCSS  
- Navegação com React Router  
- Gerenciamento de estado com Context API ou alternativa

---

## 🛠️ Tecnologias Utilizadas

- **React** – Interface declarativa e baseada em componentes  
- **TypeScript** – Tipagem estática para maior segurança e produtividade  
- **TailwindCSS** – Utilitários de estilo para um design moderno e responsivo  
- **Vite** – Ambiente de build e desenvolvimento ultrarrápido  
- **Axios** ou **Fetch API** – Para integração com APIs REST  
- **React Router DOM** – Para navegação entre páginas
